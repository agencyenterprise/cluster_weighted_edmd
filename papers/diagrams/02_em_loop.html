EM Algorithm — Full Iteration
INIT Initialization (once)
Fit standard GMM to $\{x_i\}$ (geometry only) → initial $\pi_k, c_k, \Sigma_k$
Fit initial $L_k$ per cluster from hard GMM labels
Calibrate $\sigma_k^2$ from within-cluster residuals
↓
⟳ repeat until ELBO converges
E-STEP Compute responsibilities (fix all params, update $r$)
$\log r_{ik} \propto \log \pi_k + \log\mathcal{N}(x_i;\, c_k, \Sigma_k) + \log\mathcal{N}(\varepsilon_k(x_i);\, 0,\, \sigma_k^2 I)$
where $\varepsilon_k(x_i) = f(x_i) - L_k(x_i)$ using frozen $L_k$ from last M-step
Normalize: $r_{ik} = \exp(\log r_{ik}) \;/\; \sum_j \exp(\log r_{ij})$
↓
PRUNE Remove dead clusters
If $R_k = \sum_i r_{ik} < 1$, remove cluster $k$ (Dirichlet prior drives $\pi_k \to 0$)
↓
M-STEP Update all parameters (fix $r$, optimize $\theta$)
Local model: $L_k \leftarrow \text{weighted fit from } \{(x_i, f_i)\}$ with weights $r_{ik}$
Center: $c_k \leftarrow \sum_i r_{ik}\, x_i \;/\; R_k$  (+ prior + residual gradient)
Covariance: $\Sigma_k \leftarrow \sum_i r_{ik}\,(x_i - c_k)(x_i - c_k)^\top \;/\; (\nu_0 + R_k + d + 1)$
Residual scale: $\sigma_k^2 \leftarrow \sum_i r_{ik}\,\|\varepsilon_k(x_i)\|^2 \;/\; (d \cdot R_k)$
Weights: $\pi_k \leftarrow (R_k + \alpha_0 - 1) \;/\; (P + N(\alpha_0 - 1))$  ($P$ = total points, $N$ = num clusters, $\alpha_0$ = Dirichlet prior; $<1$ promotes pruning)
↓
CHECK Convergence
$\text{ELBO} = \underbrace{\displaystyle\sum_{i,k} r_{ik}\bigl[\log \pi_k + \log\mathcal{N}(x_i;\, c_k, \Sigma_k) + \log\mathcal{N}(\varepsilon_k;\, 0,\, \sigma_k^2 I)\bigr]}_{\text{expected log-likelihood}}$
$\underbrace{- \displaystyle\sum_{i,k} r_{ik}\log r_{ik}}_{\text{entropy}} \;+\; \underbrace{\log p(\pi \mid \alpha_0) + \displaystyle\sum_k \log p(c_k, \Sigma_k \mid \text{NIW})}_{\text{priors (Dirichlet + NIW)}}$
If $|\text{ELBO}^{(t)} - \text{ELBO}^{(t-1)}| < \text{tol}$, stop. Otherwise → back to E-step.
